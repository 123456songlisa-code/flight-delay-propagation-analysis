# 简历项目表述

**航班延误传播诊断与周转缓冲优化｜独立分析**

- 基于 BTS 2024年1月54.7万条航班运营数据，使用 PostgreSQL 构建航班、航司、机场和日期分析模型，统一准点率、完成率、严重延误率及延误传播率等指标口径。
- 根据机尾号和航班时序，利用 `LAG`、窗口函数及时间间隔还原46.1万个有效轮转对；识别前序延误后的传播率为58.8%，并按延误强度、取消率和传播率筛查高风险航线。
- 搭建 Power BI 运营诊断与5/10/15分钟缓冲情景页面；静态模拟显示分别可能覆盖1.47万/2.64万/3.58万次延误起飞，并通过 Excel 完成指标复核与结果交付。

## 不可使用的表述

- 只分析了一个月，不写“百万级数据”或“全年规律”。
- 不写“增加10分钟缓冲实际降低了X%延误”，只能写“静态模拟可能覆盖”。
- 不把风险评分描述为行业标准。
- 不声称项目来自真实航司委托。
