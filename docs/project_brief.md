# 项目简报：航班延误传播诊断与周转缓冲优化

## 业务背景

航班延误会沿同一架飞机的后续航段传播。仅比较航司或机场的平均延误，无法回答哪些轮转计划容易放大延误，以及增加少量计划缓冲是否可能覆盖部分后续晚点。

本项目模拟航司运营分析团队的工作场景，使用公开 BTS 航班数据还原飞机轮转，定位高传播风险航线，并对 5、10、15 分钟周转缓冲进行静态情景测算。

## 分析问题

1. 当前样本的准点率、完成率、取消率和严重延误率是多少？
2. 同一机尾号的前序延误在多大程度上传导到后序航班？
3. 哪些航线同时具有高延误率、高严重延误率和高传播率？
4. 在不改变实际运行时间的静态假设下，增加不同缓冲可覆盖多少延误起飞？

## 决策边界

- 轮转关系由机尾号、时间顺序及机场衔接近似还原，不等同于航司内部排班。
- 延误传播率描述条件相关性，不证明前序延误是唯一因果来源。
- 缓冲模拟仅重新计算相对计划时间的延误，不考虑飞机利用率、机组工时、机场时刻和旅客衔接成本。
- 样本输出只代表输入文件覆盖期；扩大到全年需下载12个月原始文件并重新运行。
